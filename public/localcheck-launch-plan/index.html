4. Apple Compliance Gates (Sentinel owns)

Five things that auto-reject in 2026 if missing:

  1. Account deletion in-app (since 2022, strictly enforced). Settings → Delete Account → confirmation → server-side wipe within 30 days.
  2. Privacy Manifest (PrivacyInfo.xcprivacy) declaring data collection categories + reasons for required-reason APIs (UserDefaults, FileTimestamp, SystemBootTime, DiskSpace). Required since May 2024.
  3. App Tracking Transparency prompt if any third-party SDK touches IDFA (most analytics do).
  4. Encryption export compliance: ITSAppUsesNonExemptEncryption=false in Info.plist if using only standard HTTPS.
  5. Support URL + Privacy Policy URL live on the public web before submission. Use generativejesse.com/localcheck-privacy and /datingdata-privacy.
DoD: Sentinel runs a pre-submit audit script. Returns JSON with pass/fail for each of the 5 gates. Build does not advance to "Submit for Review" until all 5 pass.

7. TestFlight Beta (Sentinel runs, 5-14 days)

  1. Internal testing: up to 100 testers, no review required, instant.
  2. External testing: up to 10,000 testers, requires Beta App Review (24-48 hr first time). Need group + public link.
  3. Crash-free rate must be >99% before submitting for review. Sentry SDK integrated.
  4. Minimum 5 external testers giving feedback for 7 days before App Store submit.
DoD: Both apps have ≥5 active TestFlight testers, ≥99% crash-free, ≥3 written feedback notes per app addressed or triaged.

8. App Store Submission (CoS submits, AJ approves)

  1. Run Sentinel pre-submit audit (gate from §4).
  2. Select build in ASC → fill "Version Information" → "Submit for Review".
  3. Review time 2026 median: 24-48 hours. First-ever submission can run 3-5 days.
  4. If rejected: response time matters. Reply via Resolution Center within 24 hr with concrete fix + new build. 90% of rejections resolved in 1 round if addressed properly.
  5. Common 2026 rejects to pre-empt: 4.2 (minimum functionality — biggest), 5.1.1(v) (account deletion missing), 2.3.3 (low-res screenshots), 3.1.1 (Stripe for digital goods).
DoD: Status = "Ready for Sale" in ASC. App live on App Store. AJ has downloaded production build to his personal device and verified IAP flow.
